# Evaluation Data

`test_cases.csv` is generated by `python eval/prepare_fleurs_eval.py`. The
script downloads a deterministic 10-example subset per language from the
Hindi (`hi_in`), Kannada (`kn_in`), and Tamil (`ta_in`) test configurations.
It pins the Google FLEURS dataset revision recorded in the manifest and
downloads only the selected audio from each language archive. Downloaded audio
is ignored by Git and is not included in the repository.

Attribution: Google FLEURS dataset, licensed under Creative Commons
Attribution 4.0 International (CC BY 4.0). Dataset card:
https://huggingface.co/datasets/google/fleurs. License:
https://creativecommons.org/licenses/by/4.0/.

FLEURS consists of read speech, not lecture recordings. This subset is suitable
for a small multilingual ASR check only; it is not evidence about performance
on noisy, fast, code-switched, or long-form lecture audio. The dataset provides
no gold notes or quiz answers.
